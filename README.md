# 本地数值作业与结果归档

在本机运行的数值作业归档：接收有符号 64 位整数序列，计算总和与平方和，
支持作业提交、查询、取消、依赖与结果持久化。

## 能力

- **提交**：记录提交人、幂等请求号、整数序列与种子，接受后返回稳定作业号；
  空序列、引用不存在依赖的提交被拒绝且不产生记录。
- **依赖**：支持一次等待多个上游——提交时给出有顺序的上游作业号列表，
  列表中的作业全部成功且归档完整后本作业才可运行；各上游的总和按列表
  顺序逐个追加到原始序列末尾（不按完成先后改变输入）。列表只能引用提交时
  已存在的作业，不含零与重复作业号；引用已失败/取消的上游仍接受提交，
  但新作业立即失败。单依赖方式继续可用；等待依赖的作业不挡住后面可运行
  的作业。
- **计算**：输出总和与平方和；结果超出 int64 范围时作业失败并说明原因，
  不留下成功结果。依赖作业成功归档后，其总和作为额外整数追加到本次输入末尾。
- **调度**：本地一次只运行一个作业，其余可运行作业严格按提交先后执行；
  等待依赖结果的作业会被跳过，不挡住后面可运行的作业。
- **状态**：区分排队（等待计算位置 / 等待依赖结果）、运行、成功、失败、取消；
  依赖失败或取消会沿链条级联，失败信息指出阻断它的作业。
- **幂等**：请求号在同一提交人内有效；同人同号同内容返回原作业，
  次序/种子/依赖变化返回冲突并保留原记录；并发重复提交只建一个作业。
- **取消**：排队与运行中的作业可取消，取消后该作业及下游不再产生成功归档；
  重复取消已取消作业仍成功，取消已成功/失败作业返回不能取消且原结果不变。
- **归档**：成功记录保存原始参数、实际参与计算的输入摘要、结果摘要、
  计算日志与校验值；相同有效输入与种子得到相同结果摘要与校验值
  （作业号与时间不参与）。成功状态与完整归档在同一次原子写入中可见。
- **查询**：按作业号读取详情，或按提交人与提交时间范围（两端包含）列举，
  起始晚于结束拒绝，结果按提交先后排列；返回数据为拷贝，外部修改不影响记录。
- **持久化**：重新打开目录后，提交、取消与完成结果不丢失，幂等号继续生效，
  排队作业继续处理；上次关闭时仍在运行的作业标记为失败（计算被中断）并阻断下游。

## 使用

```go
store, err := numeric.Open("/path/to/archive")
if err != nil { ... }
defer store.Close()

job, err := store.Submit(numeric.SubmitRequest{
    Submitter: "alice",
    RequestID: "req-001",
    Values:    []int64{1, 2, 3, 4},
    Seed:      42,
})
// ...
detail, err := store.Get(job.ID)
if detail.Status == numeric.StatusSucceeded {
    fmt.Println(detail.Archive.Sum, detail.Archive.SumOfSquares)
}
```
